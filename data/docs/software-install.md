# Installing Software

## Self-service
Approved software can be installed without admin rights:
- Windows: open **Software Center**.
- Mac: open **Self Service**.
Approved list includes: Microsoft 365, FortiClient VPN, Zoom, Adobe Acrobat Reader, 7-Zip, Notepad++, Google Chrome.

## Other software
Software not in the list needs approval:
1. Create a ticket with category `software`.
2. Write the software name, why you need it and if it costs money.
3. Your manager must approve paid software.
IT checks security and licence, usually within 3 working days.

## Not allowed
- Pirated or cracked software.
- Private cloud storage (private Dropbox, private Google Drive) for company data.
- Browser extensions that read all websites, unless IT approved them.
