# Email and Outlook

## Mailbox size
Each mailbox has **50 GB**. When it is 90 % full you get a warning. Delete large attachments or archive old emails.

## Shared mailboxes
Shared mailboxes (for example `sales@example.com`) appear automatically in Outlook within 1 hour after IT gives you access.
To request access, create a ticket with category `software` and name the mailbox.

## Out of office
Outlook > File > Automatic Replies. Set start and end date.

## Phishing
- Suspicious email? Do **not** click links or open attachments.
- Use the "Report phishing" button in Outlook.
- If you already clicked a link or entered your password: reset your password immediately and create a ticket with priority `high`.

## Outlook problems
- **Outlook does not open**: close it, then start it with "outlook.exe /safe" in the Run dialog (Win+R).
- **Emails stuck in outbox**: check internet / VPN, then restart Outlook.
